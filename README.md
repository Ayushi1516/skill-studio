# SkillStudio - Learning Platform

A React-based learning management system featuring course management, student dashboards, and admin controls.

## Tech Stack
- **Frontend:** React, TypeScript, Vite, Redux Toolkit
- **Styling:** Bootstrap, Custom CSS
- **Backend:** JSON Server (Mock API)

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run the Project:**
   You need two terminals open:
   - Terminal 1 (API): `npm run server`
   - Terminal 2 (Frontend): `npm run dev`

3. **Access the App:** Open `http://localhost:5173`
